    How a map is made

    {{ROWS}} rows × {{COLS}} characters

    A mission is a list of {{ROWS}} strings in missions.js, one per row, each exactly {{COLS}} characters long. Every character is one cell. parseLevel in engine.js turns the text into a grid of blocks plus the spawn points. Point at a cell in either view to read it. Rows and columns count from 0, as they do in the code.

    Point at a cell to read it.

    The parser requires

    • Exactly {{ROWS}} rows, each exactly {{COLS}} characters.
    • Exactly one @. A second one is an error.
    • At least one enemy letter.
    • No characters outside the legend. Anything else stops the game with an "Unknown map cell" error.

    The tests check

    • There are exactly {{MISSIONS}} missions, with checkpoints at {{CHECKPOINTS}}.
    • Each mission has between 1 and 8 enemies.
    • You can reach every enemy: either drive next to it (crates count as open, since a mine blast clears them) or see it down a clear straight line from somewhere you can drive.
    • The enemy AI plays every mission for 20 seconds with 3 different seeds without a tank ending up inside a block or a shell inside a wall.
